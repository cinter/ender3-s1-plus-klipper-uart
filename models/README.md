When available, keep each part in its own folder with source CAD, printable STL, licence/attribution, print orientation/material/settings, fasteners, revision and fit photographs.

The enclosure must allow for the actual screen revision, Pi connectors, display ribbon bend, ventilation and strain relief. The single-cable harness must be serviceable without pulling individual GPIO jumpers.
